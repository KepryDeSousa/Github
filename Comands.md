# Comandos git

## Boas praticas
verificar se existe alterações no codigo
com o comando 
> git pull 
## Comandos para setar a maquina git
git config --global user.name

git config --global  user.email

## Verificar branch atual
> git branch  (pode usar com --list)

## Pegar infors do git atual
> git status


## Criando Branchs no Git
> git checkout -b nome-da-branch
> * -b para criar uma branch (seguido do nome referente)
> * -d para deletar uma branch 

## Setando oring
git push origin main


# Terminal 
## Listar pastas
> dir

## Criar pastas 
> mkdir nome-da-pasta

## Entrar em pastas
> cd path-da-pasta

## Abrir o vs code
> code . (passar o path do projeto ou usar ponto "." para executar no local)
